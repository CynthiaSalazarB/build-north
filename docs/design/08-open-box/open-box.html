7BRed to Green

The session as a test run: the $ reality-check prompt, the folder tree, jwt.spec, the guess typed into toScore(), the checks list with queued and in progress, and Expected over Received.

7DBlack Box

The box: eight corners for eight points. Closed on the start screen, marked with the guess, then opened on the result with the proved corners turned to glass. A mini box shows progress in the top bar.

7EYour Pair

The pair: a 40dp avatar beside every question, peeking from behind the box on the start screen. At level 5 the seats swap and it listens. It never reacts to the score, so it stays off the result.

7FWarm Editor

The voice and the result: Newsreader for what the tutor says and mono for what the system says, the gap as a forecast error, where the gap came from with the right answers, one normal line and one next step. Both themes have a day and a night mode, as 7F had editor and paper.
